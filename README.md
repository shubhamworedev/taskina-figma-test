# Page Selection UI – Test Assignment


This project is a React-based page selection component built as part of a test assignment.
The UI logic is driven by multiple interaction states `(default → hoverBlue → disabledHover → checked)` that were implemented after carefully studying all element interactions provided in the Figma design.


Link - https://taskina-figma-test.vercel.app/

Before development, I carefully reviewed the Figma design, including:
- Component behavior
- Hover states
- Disabled states
- Checked states
- The interaction flow between repeated clicks

This ensured that the UI and interaction patterns match the design exactly as intended.

### Tech Stack

- React (Vite or CRA)
- CSS
- JavaScript ES6
- Component-driven architecture
